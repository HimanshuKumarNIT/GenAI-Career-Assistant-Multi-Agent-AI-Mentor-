# GenAI-Career-Assistant-Multi-Agent-AI-Mentor-
AI-powered multi-agent career assistant that helps users learn GenAI, prepare resumes, practice interviews, and optimize job search — built entirely with open-source tools.
 
# Overview

The GenAI Career Assistant is a practical AI assistant designed to help users navigate their career in Generative AI. It provides guidance for learning, resume building, interview preparation, and finding job opportunities. The tool integrates multiple AI agents for a smooth, personalized experience.

# Key Features

Learning & Tutorials: Offers personalized learning paths in Generative AI and helps create tutorials or content based on user queries.

Resume Assistance: Guides users in building optimized resumes for AI roles.

Interview Preparation: Conducts mock interviews and provides answers to technical questions.

Job Search Support: Provides personalized suggestions for job listings and company research.

# Tech Stack

Python, Jupyter Notebook

LangChain, LangGraph for agent workflows

Gemini LLM for natural language interactions

DuckDuckGo Search for real-time information retrieval

Markdown generation for saving resumes, tutorials, and interview logs

# How It Works

Query Categorization: User inputs are classified into Learning, Resume, Interview, or Job Search categories.

Routing: Conditional routing sends queries to the relevant agent.

Agent Execution: Each agent handles user queries and generates outputs (tutorials, resumes, interview notes, job listings).

State Management: Maintains conversation context to improve accuracy and follow-ups.
